# أصداء الديرة — Aldeereh App

نموذج تفاعلي لتطبيق صحيفة أصداء الديرة (aldeereh.com).

- `index.html` الصفحة الرئيسية للتطبيق
- `support.js` ملف التشغيل المطلوب
- `assets/` الشعار والأيقونات

## النشر
اربط المستودع مع Netlify أو Cloudflare Pages أو GitHub Pages (الفرع `main`، المجلد الجذر، دون أمر بناء).
