# أصداء الديرة — الموقع

موقع ويب متجاوب (جوال + حاسوب) يجلب الأخبار مباشرة من aldeereh.com عبر WordPress REST API، وينقل كل ميزات التطبيق الأصلي.

## الملفات
- `index.html` الصفحة الأساسية (مسارات نظيفة مثل `/news/123`)
- `js/core.js` النواة: الرئيسية، الأخبار، المقالات، التعليقات، الوفيات، الأفراح، التوفير
- `js/notify.js` الإشعارات والعاجل وساعات الهدوء والملخص · `js/ads.js` الإعلانات
- `js/card.js` بطاقة المشاركة 1080×1350 · `js/services.js` الصلاة والطقس والتقويم والدليل والاستطلاع…
- `js/settings.js` الإعدادات · `js/boot.js` التشغيل · `sw.js` العمل دون اتصال
- `js/data.js` و`js/parsers.js` بيانات احتياطية ومحللات WordPress من النموذج الأصلي
- `prototype/` النموذج الأصلي (للرجوع فقط)

## النشر (Cloudflare Pages)
بلا أمر بناء، المجلد الجذر `/`، ولا يوجد `404.html` فيعيد Cloudflare `index.html` لكل مسار.
عند تغيير ملفات الواجهة، ارفع رقم `V` في `sw.js` ليتحدث التخزين المؤقت.

## يحتاج إعداداً في موقع WordPress
انظر `prototype/design_handoff_aldeereh_app/README.md`: السماح بالتعليقات المجهولة، وحقول subtitle وviews، وترويسة CORS لمجلد uploads.
